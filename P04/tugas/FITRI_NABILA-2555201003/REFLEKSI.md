# Refleksi Praktikum P04

Pada praktikum P04, saya belajar membedakan data yang dimiliki oleh kelas dan data yang dimiliki oleh masing-masing objek. Saya jadi paham bahwa pencacah jumlah alat harus menggunakan atribut kelas, bukan `self`, supaya jumlah alat yang terdaftar bisa bertambah dengan benar.

Saya juga belajar menggunakan `@classmethod` untuk membuat objek dari data CSV dan `@staticmethod` untuk memeriksa tarif tanpa harus membuat objek terlebih dahulu. Selain itu, saya mengetahui bahwa penggunaan list kosong sebagai nilai default bisa membuat data beberapa objek tercampur. Hal ini bisa diperbaiki dengan membuat list baru untuk setiap objek.

Dari praktikum ini, saya sadar bahwa penempatan atribut dan pemilihan method harus sesuai kebutuhan. Saya juga belajar bahwa pemeriksaan kode saja belum tentu menemukan semua kesalahan, jadi program tetap perlu diuji.

Hal yang masih ingin saya pahami lebih lanjut adalah kapan sebaiknya menggunakan method biasa, `@classmethod`, dan `@staticmethod` agar tidak salah saat membuat program.
